# 複数年の成績・表彰の整合性

最新main（PR406取り込み済み）で、年末の一軍所属だけを対象に年度成績を保存していた。一軍で出場してから二軍へ降格した選手は、年度更新時に現在成績がリセットされる一方、その年度の履歴と通算集計が欠落する。タイトル・MVP・歴代記録も一軍所属だけで集計していた。

また、引退選手を所属から外してから表彰を集計するため、引退する選手の最終年の成績が対象から漏れていた。

## 修正

- 年末に二軍にいる選手でも、保存された一軍出場記録があれば年度成績を保存してからリセットする。BFがある無失点・投球回0の登板も保持する。ポストシーズンだけ出場した選手の記録も保存する。
- 一軍出場のない二軍選手・新入団選手に一軍の年度成績を作らない。二軍成績のstats2を一軍成績に混ぜない。
- 表彰・タイトル・歴代記録には、二軍所属の一軍出場者も含める。集計基準・規定打席／投球回は変更しない。
- 引退・育成終了・CPU更改などで所属を変更する前の完了シーズンから表彰・記録を集計する。引退選手の現在成績を通算へ二重加算しない。
- FA移籍前の成績保存と、未出場の新所属で年度成績を作らないPR406の扱いを維持する。

## 検証の範囲

回帰テストでは、実際の年度更新フックを使い、12球団で一軍／二軍を交互に移動して3回更新する。2回目の更新後にJSONへ保存して再生成し、成績・通算・年齢・在籍年数・球団所属・優勝履歴の保持と、二重操作の防止を確認する。試合成績は検証用の固定値であり、3シーズンの物理シミュレーションを完走したという検証ではない。

別のケースで、引退年の表彰、実測0の防御率／勝率1、ポストシーズン成績、保存失敗後の再試行、一軍の継続契約の残年数とFA登録日数を確認する。既存のFA・契約・保存テストも併せて実行する。

## 次の課題

二軍選手の契約残年数は現在の年度更新で減らず、編成計画・個別更改・CPU更改・FA宣言も主に一軍だけを対象にしている。残年数だけを減らすと、合意できない満了選手が発生するため、本PRでは変更しない。二軍・育成を含む契約対象と確定操作を揃える単位で続けて扱う。

過去に保存されなかった年度の成績は復元できない。旧データから成績を推定して埋めない。シーズン途中の移籍について所属別成績が保持されていない場合、その内訳を新たに作らない。本PRはゲーム全体の長期経済・全履歴の永続化・全所属変動を保証するものではない。

画面変更はなく、スマホ実機目視・ブラウザE2Eは未実施。投手交代、物理演算、要求年俸の算式・係数、FA宣言率、Sitesは変更していない。表彰は更改評価にも参照されるため、正しく受賞対象に戻った選手の要求額が変わる場合はある。
