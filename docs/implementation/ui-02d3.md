# UI-02D3 — 二軍ランキング・年度別成績

基準main: `83d25a3fe8077489cdc1cd7e1d913211a36e1f24`（PR #459マージ後）。GitHub mainと新規cloneのSHAを照合し、専用ブランチを使用。添付ZIPは実装基準にしていない。ユーザーの実装依頼とDES-01を仕様とし、再承認を求めず既存画面を移行した。

## 目的・設計

スマートフォンで二軍成績から候補を探し、保存された年度別実績・実績球団を確認し、現在の選手詳細から起用へ進む。

- FarmRankingsをネイビーの範囲見出し・白い表・青い操作へ移行。年度／リーグ／実績球団、打撃／投球タブ、指標選択、主要／詳細列、規定打席フィルタを配置。選手名と選択指標を優先し、実施状況・理由・説明を展開式へ移動。
- 一軍と操作部品・タブの意味論を揃え、二軍固有の規定・母集団・指標・順位は維持。二軍は計数指標にも既存の規定打席フィルタを適用し、投手規定やセーブ／ホールドを新設しない。ERA昇順・その他降順、整数アウト数の投球回表示、同率順位、保存済み同時受賞を維持。
- 名前から読取専用の二軍記録へ。ランキング選択範囲と両リーグ・球団間合計を区別し、記録側の年度も切替可能。球団別内訳は保存された全計数指標とselectorの投球回を表に表示する。
- 現役導線はIDで現在の一軍・二軍を照合し、実在する現在選手と現在球団を既存onPlayerClickへ渡す。過年度の名前や実績球団から能力・現在所属を作らない。退団選手はplayerIdだけで保存記録を読む。PlayerModal・起用への既存導線を再利用。
- 記録を開くと閉じるボタンへfocus、Escape／閉じる後は元の選手名とページ位置へ復帰。現在選手のmodalを閉じると記録内のリンクへ戻り、一覧条件と記録を保持する。タブは矢印・Home・Endに対応。
- 実測0、分母0の算出不可、未記録、旧推定、途中記録、未実施を分離。過年度に保存されていない未実施理由は未記録とし、現在の編成から推測しない。既存pending表彰の表示互換性も維持。

## 維持した仕様・対象外

selectFarmRanking／selectFarmPlayer／selectFarmRecord／selectFarmTeams／calcMeasuredFarmAwardsとfmtAvgを再利用。エンジン、成績計算、Worker、編成・疲労・成長・CPU補強、保存スキーマ、ナビ構成は変更していない。FIX-S3、試合結果・まとめシム、UI-03、UI-02Eは対象外。

AGENTS・CONTRIBUTING・ROADMAP・DESIGN_SYSTEM・TEST_STRATEGY・青写真、UI-02A〜D2記録、PR #455〜#459のマージ状態と対象実装を確認。同じlockの既存node_modulesを再利用。既存関連4ファイル29件が基準mainで成功。
