# UI-02D2 — 一軍リーグランキング

基準main: `c4558ae44d5c7e6f7563c9d89eba4aff6ce1acf0`（PR #458反映）。GitHub main、マージ状態、ローカルfetchのSHAを照合。添付旧ZIPは実装基準に使用しない。

## 目的・範囲

全球団／リーグ別の一軍成績から候補を探し、選手詳細・2人比較を確認して編成へ戻れる状態にする。既存LeaderboardTabをDES-01へ移行し、#458の球団別一覧と記録条件・欠測ガードを共有する。

対象：打者／投手、リーグ・規定到達者の絞り込み、指標・方向の選択、主要／詳細列、並び順の先頭3選手、年度・現在所属・役割・状態・負傷、詳細／比較の導線。二軍ランキング、育成・会話、まとめ結果・試合詳細、UI-03、ゲーム処理・保存形式・ナビID・成績の式や丸め精度（FIX-S3）は対象外。UI-02全体の完了とはしない。

## 開始時の照合と設計判断

- AGENTS/CONTRIBUTING、ROADMAP、DESIGN_SYSTEM/TEST_STRATEGY、SPEC・青写真の関連部分とUI-02A/B/C/D1検証記録を確認。基準mainの関連12件が成功。
- 一軍母集団は既存`seasonParticipants`を維持。二軍所属の一軍出場者を含め、statsだけを一軍記録として読む。二軍実測／旧stats2／年度別／通算を合算しない。球団・リーグは現在所属と明示し、過去の実績球団を現在所属へ付け替えたという説明にはしない。
- 既存の最低打席10・最低投球回5を維持。規定は進行日基準の元の`calcQualified`を保持（打席はmax(10,floor(max(1,gameDay−1)×3.1))、投球回はmax(5,max(1,gameDay−1))）。元のisRate指定、WARへの適用も維持。計数指標では規定checkboxを無効化し、未適用を文字で説明する。表彰の固定条件とは別の一覧条件。
- 数値は#458の`firstTeamMetric`をそのまま再利用。実測0・未記録・算出不可・不正値を区別し、ソートは既存stableSortで欠測を両方向とも末尾へ。必要項目・実際の分母・既存saberの式と丸めを共有し、別計算を追加しない。WHIP等の末尾0は一覧のformatterへ揃え、数学的丸め精度は変更しない。
- 上位3名という固定名称を「並び順の先頭3選手」へ変更し、昇順でも意味を誤らせない。欠測は先頭まとめへ含めない。表の番号は既存の行順を保つ「表示順」で、同率の公式順位計算を新設しない。欠測には番号を付けない。
- 指標dropdownと方向buttonでスマホでも並び替えできる。現在のソート指標は列の先頭に保ち、主要／詳細切替で隠さない。全ての旧指標を維持。球団・リーグ・役割は固定名前セルのidentityへ移し、比較は表末尾と既存詳細から操作可能。
- DES-01の共通Button/DataTableFrameを使用。名前button、比較button、tab/panel関連付けと矢印/Home/Endを整備。名前・比較のキー操作が同時に詳細を開かないようにする。補足・先頭まとめはprimary tableの後へ置き、スマホ初期表示で名前と主指標を読めるようにした。
