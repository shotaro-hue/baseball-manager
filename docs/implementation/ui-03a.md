## 目的・対象

来季人数・年俸・残予算・交渉待ちを見ながら、自球団の方針を比較し、補強市場と結果確認を行き来する。
`OffseasonPlanningScreen` の外枠、概要、編成方針一覧、結果確認、放出／編成終了の確認をDES-01へ移行。
既存の `Button`・`MetricBand`・`StateLabel`・`DataTableFrame` と `useResultDialog` を再利用。写真なし、44px操作、対象だけに限定したCSS。
埋め込み契約更改・FA市場・成長結果の内部UI、ナビ構成、ゲーム計算、state更新責務、保存形式・キューは変更しない。

## 実装とデータ

- 年度・球団・年間の現在地と4指標を表示。人数見込みは一軍・二軍・育成から放出候補を除いた人数で、支配下枠残数ではない。人数・年俸の計算は既存 `planningSummary` を使用。
- 年俸見込みの説明を計算に合わせる。当年契約済み年俸、その他は成立済み条件、成立条件がなければ前年年俸。未合意の提示額は反映しない。FAの年俸×年数先払いと通常更改の予算計上の違いも説明する。
- 選手／所属・年俸（万円／年）・方針の3列表。全員／交渉予定／放出候補の表示フィルターを追加し、詳細は既存PlayerModalへ接続。方針変更は既存下書き更新だけを呼ぶ。
- 未記録は未記録／—、実測0は0。空一覧、対象方針なし、編成データ不一致を表示。説明・成長結果は一覧後へ置き、PCでは補足を右側に配置。
- 実際の保存結果・dirty・キューから保存中／失敗／待ち／成功／部分成功／未確認を表示。結果がないだけで保存済みとは扱わない。手動保存・再試行は既存 `handleSave` を呼ぶ。
- 自球団・補強市場・結果確認の既存タブ、契約下書きsession・viewの保存、実放出／FA／編成終了のハンドラーを保持。未合意がある編成終了は引き続き不可。
- ダイアログのTab循環・Escape・開いた操作への復帰を維持。放出により操作が消えた場合は方針一覧のsummaryへ戻す。フィルター中の方針変更で行が消えた場合は選択中フィルターへ戻す。
