# FIX-S2 — 球団比較の集計・欠測整合性

基準main: `1e607e753b09bb87da16a626f6de33377ac0f82b`（#447〜449反映）。

## 目的と描画経路

`TeamDetailScreen` → `TeamComparisonPanel` → `buildTeamComparisonRows/buildTeamMetrics` が実際の表示経路。球団比較の実測0、降格選手の一軍成績、全所属選手の契約年俸を整合させる。旧CSS・ナビ・保存形式・試合処理は変更しない。

| 指標 | 母集団・期間・欠測 |
| --- | --- |
| 打線OPS | 今季一軍出場野手。`seasonParticipants` により一軍＋一軍記録を持つ二軍選手を対象とし、`stats2` は含めない。ABとOBP分母が成立し、必要な集計キーが非負の有限数値である場合のみ算出。実測0は0.000、未成立・不完全は---。既存`saberBatter`の丸めを維持（FIX-S3対象外） |
| 強打球率 | 同じ今季一軍野手の`stats.battedBallProfile`。記録済みBIPで合算。BIPがあって分子が未記録なら---。打球記録がない選手は分母に加えない |
| 先発／救援ERA | 今季一軍出場投手。従来通り現在のrotation登録またはsubtypeに「先発」を含む選手が先発、その他が救援。IP>0かつIP/ERが記録済みなら算出、自責0は0.00。IP0・不完全は--- |
| 先発守備平均 | 現一軍の`lineup`に載る野手の能力値。シーズン出場者全体へ変更しない |
| 総年俸 | `contractPayroll`の一軍＋二軍＋育成の年間契約年俸（万円）。同一ID・同一オブジェクトを一度だけ計上。0有効、null/undefined未記録、不正型・負数・非有限値は不正 |
| 得点／試合・残予算 | 従来の球団値・計算を維持。支払済み額と契約年俸を混同しない |

比較の成績母集団はID=0も含め重複除外、一軍側の記録を優先。入力選手・配列を書き換えず、共有`seasonParticipants`・`contractPayroll`・ランキング・表彰の実装は変更しない。

年俸が一部未記録／不正の場合、確定総額は`null`とし、別の派生情報に確認済み額と未記録・不正人数を保持。表示は「---」「確認済み X万円（集計不完全・未記録N人・不正値N人）」。順位評価は実測0を含み、算出不可を除外。年俸・予算は従来通り優劣・順位を付けない。

## 検証

- 新規エンジン・React回帰14件で既存のERA0、OPS0、降格記録消失、一軍限定年俸を基準main復元でRED確認後にGREEN。独立レビューの追加保護として、小数IP、0アウト自責点、他の有効記録と欠測が混在するケースも確認。
- 対象Vitest（`analysisComparison`、`TeamComparisonPanel`、既存`clubComparisonFlow`・`LeaderboardTab`・`contractPayroll`）49件成功。ビルド成功。
- `e2e/club-comparison.spec.js`：既存の375px比較・フォーカス操作に加え、360px/390px/1440pxの実Appで成績→順位表→相手球団→比較を操作。二軍所属の一軍記録、stats2除外、ERA0/OPS0、順位、年俸350万円／不完全100万円を確認。手動保存とIndexedDBロード・再開の前後で全球団データSHA-256と比較表表示を照合。通常CIのposting-and-financeにも同specを追加。Chromiumの既存2ケース＋新規4ケースは成功（個別実行の合算）。同一ソースの再実行を避け、初回の球団名に含まれる絵文字によるテストlocator失敗を修正後、影響する新ケースだけを実行した。ローカルは競合回避の一時configで5175を使用。

## 限界・次工程

- 役割ごとの過去登板記録は保存されていないため、同一投手が先発→救援へ転向した場合の履歴役割分割は扱わない。現在のrotation/subtypeによる従来分類を維持。
- 所属外の放出・移籍選手の所属球団別履歴を復元する新機能は含めない。
- 実試合→実降格の連続操作、WebKit/iPhone実機、全E2Eは今回のローカル検証対象外。固定セーブの二軍所属一軍記録を実Appで保存・再開する検証と区別する。
- GitHub CI・PR番号は公開後の最新head結果を参照。本書の単体・ビルド結果だけではCI成功を意味しない。
