# 契約更改前の国内FA補強

## 流れ

引退整理 → **国内FA・自由契約補強** → 自チームの契約更改 → 成長結果 → 戦力外・CPU補強 → ドラフト → 翌年度。

他球団の契約更改を引退整理の完了時に1回だけ実行し、国内FA・自由契約候補を自チームの更改前に用意する。給与評価、FA資格、CPU交渉の判定基準は変更しない。CPUの残候補獲得は従来どおり戦力外処理の後に行う。自チームが更改中にFA宣言・自由契約となった選手もこの後段のCPU補強に含まれる。

外国人市場は従来どおりシーズン中の補強とし、このフェーズでは国内候補だけを表示する。補強しない選択も可能。進行前に獲得選手と条件を確認できる。

## 操作と更改対象

PR399のFA画面を再利用し、予算、登録／ファーム配属、契約総額、成績・年度別成績・比較への入口を維持する。専用フェーズでも候補同士、自チームの選手との比較を利用できる。最終契約確認と次フェーズへの進行は別の確定操作とし、連続タップを防ぐ。

更改対象は補強前に要求額を計算した既存選手に固定する。新たに獲得した1年契約選手を直後の更改対象に入れない。その選手の年俸は、更改画面の年俸総額に含める。単体画面・旧経路で対象ID指定がない場合は従来の満了条件を使用する。

## 成績と市場の保持

未契約の国内候補は翌年度も市場に残す。年齢を進め、現シーズン成績はリセットする。市場の保存済み成績は別のスナップショットとして保持する。

候補の市場移行年度・旧球団が実データから分かる場合、その成績を旧球団の年度別成績として保存する。オフシーズン加入時は自チーム・CPUとも新球団の現成績をリセットし、旧球団の成績を新球団に計上しない。同一年度を再処理して通算成績を二重加算しない。旧データで年度・旧球団が不明な場合はそれらを捏造せず、元の成績スナップショットを保持する。

通常ホームの市場への入口と外国人の第100日期限は維持する。試合、投手交代、物理演算、契約更改の減額制限・まとめて提示には変更を加えない。

## 確認

自動テストではフェーズ順、CPU更改1回、補強せず進む・戻る、契約と進行の二重操作、獲得選手の更改除外と年俸総額、ID 0との比較、年度をまたぐ候補保持、旧球団成績の保存を確認する。

目視確認・ブラウザE2Eは未実施。ユーザー確認対象は、引退整理からの遷移、候補一覧・詳細・比較、補強後の予算、終了確認、更改対象、補強なしの進行。
