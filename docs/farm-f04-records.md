# F-04: 二軍の年度閲覧・ランキング・年間表彰

基準main: `f24b5a313474fb0fc6c34a3369d06aea8268fc9d`（PR #439）。FIX-F v1.1の後続。F-01〜03の記録・保存・進行契約を維持する。

## 閲覧

既存の成績タブに二軍を追加。年度・リーグ・球団・打撃／投球・指標を切り替える。選手の現在所属ではなく当該年度の球団別実績を集計し、移籍者のリーグ間合算をリーグランキングへ混ぜない。退団・引退者も表示する。順位は同率を共有し次順位を飛ばす。率の分母0は算出不可、旧推定は対象外。規定未達者を含む途中ランキングと規定到達者を切り替えられる。

選手詳細には実測年度の切替と全対応計数を追加。ランキングからは能力・契約を捏造せず実測の読み取り専用詳細を開く。未記録、0、途中記録、旧推定、非対応を区別する。スマホ360/390px・PC1440pxを対象とし、既存の表と局所横スクロールを使う。全面CSS刷新は行わない。

当年度の未実施理由は保存済みカードの原因・不足球団・必要人数から表示する。選択球団が相手の不足で未実施になった場合も表示する。F-02の過年度archiveは原因を保持しないため、過年度理由は未記録と明示し、現在編成から推測しない。

## ゲーム内表彰規定

- 対象は開幕round 1から最終round 143まで記録した年度。途中移行年は年間表彰なし、進行中は未確定。未実施カードがあっても全roundの処理を満たせば対象。
- リーグ規定打席はリーグ内球団の最多実施数×3.1を切り上げる。打率はAB>0、規定PA到達者のH/AB。NPB公式規則とは称しない。
- 本塁打王は実出場打者でHR>0。最多勝は実登板投手でW>0。旧30回条件を新実測へ適用しない。全員0なら該当なし。
- 同率は全受賞者を保存する。先頭受賞者の既存フィールドとwinners配列を維持。球団移籍は当該リーグの実績球団名を併記し現在所属に付け替えない。
- 一軍表彰・既存保存済み旧表彰を変更しない。新表彰は既存awards内に保存し、二軍成績の新しい保存正本やDBを増やさない。

## 完了検証

所属変更・ID 0・同率・該当なし・分母0・途中移行・年度archive・保存復元をテストする。実ブラウザで3幅、年度／リーグ／球団切替、ランキングから詳細、保存再開を確認する。

性能は同一fixture/seed/環境の基準mainと修正後を比較し、5/143roundを複数回測定。計算、転送相当clone、React採用、保存、ロードを区別する。5/20年の容量は合成履歴と明記し、実プレイの年数とは混同しない。暫定ゲートはF-04による計算中央値増加20%または50ms以内、年度ranking 100ms以内、20年farm archive 20MB以内。既存全体容量と保存時間も併記し、端末RAMの厳密測定を行えない環境では未測定とする。係数調整・CPU補強AIは測定結果から必要性を報告するだけで変更しない。
