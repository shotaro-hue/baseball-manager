# 年俸・FA市場のバランス検証

## 結論

宣言率・要求年俸の係数は変更しない。複数年の計測では自然な国内FA宣言が毎年発生し、大部分に獲得先がある。一方、CPU更改が決裂してFAになった際、共有の要求額ではなく前年年俸が市場価格に残る不整合を確認したため、この経路だけ修正する。

要求5,600万円・前年1,000万円の合成選手を予算不足のCPU球団からFAにすると、修正前の市場価格は1,000万円になる。修正後は5,600万円。高年俸から要求が下がるケースも共有の要求額へ一致する。前年年俸は別フィールドに保持し、宣言理由を表示する。当年度の残契約年数は0とする。非FAの自由契約をFA宣言と同じ価格へ変更することはしない。

## 計測方法

最新main（PR403のマージ後）を基準とし、乱数seed 1と42で2026〜2028年の3シーズンずつ計測する。各年12球団が143試合を完了したことを検査する。通常はスキップされる任意実行のベンチマークを追加した。

```sh
RUN_FA_ECONOMY_BENCHMARK=1 FA_ECONOMY_REPORT=/tmp/fa-economy.json npm test -- scripts/fa-economy-benchmark.test.js
```

`FA_ECONOMY_SEEDS`（カンマ区切り）、`FA_ECONOMY_YEARS`で条件を変更できる。各シーズン終了時に途中結果も出力する。

実際の試合・成長・要求額・CPU更改・FA宣言・CPU獲得のエンジンを使用する。全球団がCPU更改・補強を行い、ユーザーの先取り獲得は行わない。年齢・登録日数・成績履歴・残契約年数を更新し、CPUの年度予算式を適用する。ドラフト・引退・ポスティング・ポストシーズン・日本一加算は含めない。従って人口補充やゲーム全体の長期経済の保証には使えない。

## 結果の読み方

`fa-economy-results.json` に修正前後の計測値を保存する。

- 満了対象・FA資格保有者・実際の宣言判定対象を分けて集計する。海外待機などの対象外を宣言率の分母に混ぜない。
- 自然宣言・更改決裂による宣言・非FA自由契約を分ける。
- その年のFA宣言者の移籍・宣言残留・未契約を分ける。市場全体の契約数と混同しない。
- 要求額は満了対象だけを集計し、年齢、打席、OPS、本塁打、投球回、防御率、救援の層別に見る。提示額と実際の契約年俸は別物。
- 更改前後と市場処理後の予算を分けて記録する。翌年は収入と年俸から予算を再計算し、既存の予算下限が適用される。

6シーズンで自然宣言は年7〜15人。更改決裂によるFAはこの条件では0人のため、価格修正の効果は通常の計測値には現れない。修正の必要性と動作は予算不足などを明示した回帰テストで検証する。低年俸選手の価格が漏れる不整合を、宣言率や年俸係数の変更で補わない。

| 指標 | 6シーズン合計・範囲 |
| --- | --- |
| 宣言判定対象（海外待機などを除く） | 459人・シーズン |
| 自然宣言 | 70人・シーズン（判定対象の15.3%） |
| 他球団へ移籍／宣言残留／未契約 | 51／17／2人・シーズン |
| 更改・市場処理前後の年俸総額変化 | 各年 +0.9〜+6.7% |
| 市場処理後の球団予算 | 53.83〜120.64億円 |

同じ選手が複数年度に含まれるため、合計はユニーク選手数ではない。金額の内部単位は万円。この条件では予算不足は発生しておらず、資金難での価格引き継ぎは回帰テストで別途確認した。資金余力が大きい点は今後の財務設計の検討材料とするが、今回の小さな整合性修正と一緒に資金ルールを変更しない。

## 未解決・限界

- 追加seed 20260911では、修正前の2027年シムが `DHなしの先発に出場不可選手が含まれています` で停止した。今回は先発編成の修正をしていない。この条件の複数年経済は評価できていない。
- 初期登録日数・個性はゲーム生成値で、実際のNPB登録日数・宣言意思ではない。数値が現実のNPBに適合したとは結論しない。
- FA行使後の再取得は既存の累積登録日数判定のままで、連年宣言を排除しない。今回の値を権利再取得を含む現実の年間頻度と比較しない。
- ユーザーの実際のセーブには成績・個性・契約・登録日数の差があり、ここでの宣言人数を保証しない。
- 全球団CPU方式であり、ユーザーが先に契約する実際の市場順序では移籍・残留先が変わる。
- 年俸見込みと手元予算の区別を維持。CPU更改の即時年俸控除、年度予算下限、ユーザー更改の即時控除なしといった既存の非対称な資金処理は変更していない。
- スマホ目視・ブラウザE2Eは未実施。Sites・物理演算・投手交代・UIは変更していない。
