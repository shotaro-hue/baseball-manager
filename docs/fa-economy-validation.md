# 年俸・FA市場のバランス検証

## 現在の結論

PR404・PR408取り込み済みのmain（`0c0f13ba470be1ef5d40d30caac7eadb2c6b3b3f`）を基準に、検証モデルをversion 2へ更新した。要求年俸・FA宣言率・予算・獲得のゲーム係数は変更していない。

一軍だけだった査定対象と旧所属検索を二軍・育成まで広げ、契約残年数は本体の `remainingContractAfterSeason` を使用する。新契約を直後に短縮せず、二軍の継続契約も更新する。一軍未出場の二軍選手に年度成績を作らず、冬の移籍前に保存済みの年度成績へ新所属の0行を追加しない。育成年数も年度更新するが、満了・再契約の処理はこの限定実験には含まない。

seed 1、42、20260911で2026〜2028年の計9シーズンを再計測し、各年12球団143試合を完了した。市場価格と共有要求額の不一致、査定対象の欠落、所属ID重複は0件。予算は有限・非負であることを検査した。

| 指標 | 9シーズンの結果 |
| --- | --- |
| 満了対象 | 4,317人・シーズン |
| 宣言判定対象（海外待機などを除く） | 1,082人・シーズン |
| 自然FA宣言 | 225人・シーズン、各年20〜34人 |
| 更改決裂によるFA／非FA自由契約 | 0／0人・シーズン |
| 他球団移籍／宣言残留／当年市場終了時未契約 | 75／18／132人・シーズン |
| 更改・市場処理前後の所属選手年俸総額変化 | 各年 −7.70〜−2.83% |
| 市場処理後の球団予算 | 63.19〜125.50億円 |

同じ選手が複数年度に含まれ、合計はユニーク選手数ではない。「未契約」はその年の宣言者の当年市場終了時の状態で、翌年にも市場へ残る選手を含む。年俸総額は所属選手だけなので、未契約による減少と個人の減俸を混同しない。金額の内部単位は万円。

FA宣言者の132/225人が当年未契約になった。コードでは一軍28人のCPU球団は支配下FAを候補から除外する一方、ユーザーは二軍配属で獲得できる。これは獲得余地を狭める要因と考えられるが、未契約の全件がこの条件だけで生じたと断定しない。宣言率や要求額を上げる前に、獲得・配置ルールとシム経路の更新差を確認する。詳細は [ゲームロジック監査](game-logic-audit.md) を参照。

## 再実行

```sh
RUN_FA_ECONOMY_BENCHMARK=1 \
FA_ECONOMY_SOURCE_COMMIT=0c0f13ba470be1ef5d40d30caac7eadb2c6b3b3f \
FA_ECONOMY_SEEDS=1,42,20260911 FA_ECONOMY_YEARS=3 \
FA_ECONOMY_REPORT=/tmp/fa-economy.json \
npm test -- scripts/fa-economy-benchmark.test.js --maxWorkers=1 --minWorkers=1
```

通常はスキップする。`FA_ECONOMY_SOURCE_COMMIT` は検証対象のゲーム本体を識別する値であり、検証補助コード自体のコミットではない。各シーズン後に途中結果を保存する。完走の判断にはすべてのseed・年度が報告に含まれることとテスト成功を確認する。

最新版の計測値は `fa-economy-current-results.json`。`fa-economy-results.json` はPR404作成時の修正前後の歴史的記録として保持する。旧モデルの対象・年度更新が違うため、数値の増減を今回のゲーム係数変更の効果として扱わない。

## 検証の範囲と限界

- 実際の試合・成長・表彰・査定・CPU更改・FA宣言・CPU獲得エンジンを使用する。全球団CPUで、ユーザーの先取り獲得は行わない。
- 年度更新は検証用の補助処理。残契約年数は本体の共有関数を使い、成績保存・所属区分も本体に合わせた。IndexedDBへの保存やUIを通した年度移行は含まない。
- ドラフト、引退、ポスティング、育成満了、ポストシーズン、日本一加算、外国人市場の毎年追加は含まない。人口補充・育成循環・ゲーム全体の長期経済の保証には使えない。
- 初期の登録日数・個性はゲーム生成値で、実際のNPB観測値ではない。FA再取得も累積登録日数判定のまま。NPBの実際の年間宣言率と直接比較しない。
- 更改決裂FAと資金不足は今回の自然経過では発生しなかった。その経路は既存の回帰テストで検証する。
- 旧モデルでseed 20260911の2027年に先発不正で停止した事例は、今回の条件では再現せず3年完走した。全seed・旧セーブで解消した保証ではない。
- CPU更改の即時控除、ユーザー更改の即時控除なし、年度予算下限などの既存資金処理は変更していない。試合モードによる収入・登録日数の差も監査の未修正課題である。
- 実機目視・ブラウザE2Eは未実施。Sites、投手交代、物理演算、ゲームUIは変更していない。
