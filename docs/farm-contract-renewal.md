# 二軍・育成を含む契約更改

PR407で確認した更改対象の漏れを修正する。編成計画、個別／まとめて提示、未合意による進行制限、更改の確定、戦力外・自由契約、CPU更改、FA宣言、年度更新で一軍と二軍を同じ所属選手として扱う。

- 合意した選手は現在の一軍／二軍所属を維持する。二軍選手を更改時に自動昇格させない。育成選手は育成のまま更改できる。
- 継続契約と今オフの契約済み選手は更改・放出対象から除外する。二軍・育成の未合意があれば編成終了を止め、放出候補なら最終確認で確定する。二軍を放出した確認では所属人数を表示し、一軍の登録人数を誤って減らさない。
- 旧セーブの更改途中に二軍が抜けていた場合、既存の合意・提示・交渉ログを維持して対象を追加する。二軍年俸を更改対象と対象外の両方に数えない。編成結果・ドラフトまで進んだ旧セーブのCPU更改をやり直すことはしない。
- CPUも二軍・育成を更改し、合意できない選手を一軍と二軍の両方から除く。通常の二軍選手は既存の登録日数によってFA宣言できる。育成選手はFA宣言させず、減額制限超過への不同意や自由契約は別に扱う。

## 年度更新と育成の満了

既存の契約残年数を一軍・二軍共通で1年減らす。今オフに結んだ契約は次シーズンから始まるので、その直後の更新では減らさない。ドラフト新入団にも契約年を記録する。未記録の残年数を0とみなさず、FAの一軍登録日数は年度更新で加算しない。

例：2026年のシーズン終了後に結んだ3年契約は、2027年の開始時も残り3年。従来はこの時点で2年になっていた。一軍・二軍とも、以後の年度更新で2年、1年と進む。

育成3年満了で自由契約にする既存ゲームルールは維持する。通常の育成更改の年数はその満了までに収まる範囲とし、まとめて提示の下書きも上限内に調整して確認画面に表示する。満了した選手は履歴と市場に残し、育成として再契約した場合は育成年数を0から再開する。ユーザー・CPUとも育成で獲得した選手をファームに置き、CPUの市場契約も既存の育成最低年俸を使う。支配下への転換機能やFA資格の基準は変更しない。

二軍から放出した選手は市場へ旧所属の区分を引き継ぐ。一軍出場記録がない場合、一軍の年度成績を作らない。記録がある場合は旧球団の成績を保持する。旧セーブで既に短くなった残年数や失われた成績は推定で補わない。

## 検証

追加回帰テストで、ID 0の二軍更改、放出確認、重複処理防止、未合意による進行制限、旧セッションへの対象追加、CPU更改と自由契約、二軍のFA宣言／育成の除外、年度更新、育成満了・再契約、未出場選手の履歴、3年連続の更改・保存再生成を確認する。

既存の更改UI、FA市場、減額制限、成績保存・再開・複数年度のテストも実行する。実機目視・ブラウザE2Eは未実施。要求年俸の算式・係数、投手交代、物理演算、Sitesには変更を加えない。
