## 追加した処理

`src/engine/seasonContract.js`は合意年度・合意フェーズ・新規/更改から効力開始/終了年度を決める。シーズン中新規1年は当年で満了し、オフの1年は翌年だけ有効。シーズン中の更改は翌年から、開幕前の更改は当年度から有効とする。後者は実装時の判断であり、既存長期契約への重複更改を許すものではない。残年数は対象年度から導出し、来季契約を当年度残数に混ぜない。ポストシーズン・未知version・不正値は拒否する。

新正本の金額は万円の非負整数。0は記録値として保持し、未記録と区別する。既存の小数年俸を自動で丸める移行は実装していない。契約金額の最小額・FA3年/更改7年等の経路別制限は、接続時の取引validatorへ残す。

`src/engine/monthlyPayroll.js`は厳密な`YYYY-MM-DD`で2月1日以上12月1日未満の10か月を扱う。月中は実暦日で分配し、累計の丸め差分を費用にする。計算中だけBigIntを使い、返り値はJSON保存可能な通常値のみ。年俸・所属・予算・保存・乱数は書き換えない。

| 年俸1億円の加入日 | 当年度負担（万円） | 表示用年俸（万円） |
|---|---:|---:|
| 2/1以前 | 10,000 | 10,000 |
| 4/1 | 8,000 | 10,000 |
| 6/1 | 6,000 | 10,000 |
| 7/1 | 5,000 | 10,000 |
| 7/16 | 4,516 | 10,000 |
| 7/31 | 4,032 | 10,000 |
| 11/30 | 33 | 10,000 |

7/1加入の3年契約は額面30,000万円、負担は2026年5,000・2027年10,000・2028年10,000の計25,000万円。移籍で区間を分けても合計費用と満了年度を維持する。

`quoteContractPayroll`のtenuresは給与負担者の期間で、現役名簿とは別。加入日〜最終年度12/1を順序付きの半開区間で覆い、重複/空白/逆転を拒否する。4〜7年目と同一球団への復帰も集計する。保証解雇後の負担者記録、正式引退/ポスティングの解除合意、年俸改定の適用は後続工程。このquoteは途中解除の清算関数ではない。

## 実際に実行した現行経路

現行の不整合を将来の必須動作にしない。観測値はJSONへ出し、既存のバグを固定するassertionは追加していない。

| 経路 | 観測 | 次の接続条件 |
|---|---|---|
| 手動FA | 年俸10,000×3年で30,000万円控除。同年オフの残年数3・再更改対象外 | 効力年度と当年按分、全年度審査へ |
| CPU FA | 同じ年俸で単年・10,000万円控除 | 人と共通の費用審査。複数年評価は後続 |
| 通常更改 | 合意時控除0、年俸は即座に新額、条項保存 | 当年度を維持して翌年留保を置換 |
| CPU更改 | 11球団の更改を実行。給与を残枠から控除 | 人と対象年度・留保を統一 |
| 新人 | 年俸500万円、即時控除0、再適用で重複0 | 受諾済み留保→加入時確定の置換 |
| トレード | 所属と500万円の両側更新。給与移管による予算更新なし | 既負担を売手に残し残期間/将来年度を買手へ |
| 発掘 | 年俸10,000万円控除、残年数2。新しい署名年なし | 契約ID・開始日・当年按分を共通取引へ |
| 支配下化 | 年俸240→420万円、差額180万円控除 | 7/16変更例は変更前132＋変更後190＝322万円 |

| コーチ効果 | 同じ乱数列の若手で無/1人/2人の指導を比較し加算の差を観測 | 費用引下げと重複効果対策を同時接続 |

| 登録期限 | 実日程8/1・106ラウンドで国内FAは通過、外国人は旧100ラウンド制約で拒否 | 全経路の共通7/31暦日判定。CS等8/31資格は別審査 |

## 静的な金額候補

seed 20261026の現行実選手初期化、全12球団の年俸（欠測0）と実日程の収益予測を使用。通常指導陣は固定運営費に含む設計仮定。追加専門コーチ5人×3,000万円と新人8人×最低420万円を試算枠に入れた。新人8人はストレス条件であり、本番留保を固定人数へ戻す提案ではない。

| 収益からの配分候補 | 支援なしで試算枠が不足する球団 | 不足最大（万円） |
|---|---:|---:|
| 50% | 6 / 12 | 188,675 |
| 65% | 3 / 12 | 90,852 |
| 80% | 0 / 12 | 0 |

50%/65%を支援なしで全球団へ適用する候補は除外。支援額を校正する組合せは残し、80%を採用値とはしない。余剰と補強/投資の機会費用を含む動的校正は未実施。平滑化1/3年・増減上限10/15%は接続後のGM-01で比較する。
