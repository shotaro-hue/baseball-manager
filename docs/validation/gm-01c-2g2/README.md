## 制度とゲーム側の簡略化

[選手会公開FA規約2009版](https://jpbpa.net/wp-content/uploads/2021/12/fa2009.pdf)5〜6ページの画像で、第10条3の初回A50/B40%、同リーグ優先・低勝率優先と第10条4の反復A25/B20%を確認した。2009年資料を現行最新版と扱わない。G-1の保護対象・28人方針を継承する。

未精算の現在受諾済み案件をまとめて裁定し、未受諾の将来獲得を予測しない。同率は推定せず保留。オフは翌2月1日効力、加入待ちを経て翌春二軍へ加入する。候補表示は移管承認ではなく、翌年度契約の未確定は先に解決する。順位資料はtrusted stateの新しい入力契約で、旧セーブから推定しない。

## 影響・未検証

人的補償の新stateを旧保存へ混ぜず、既存の本番hook/CPU/Worker/UIへ接続しない。通常トレードの退団参照除去を純粋関数へ抽出して共用した。従来の移籍配置、通常トレード期限、金融例外、登録資格は変えない。

FA獲得人数・期限自動処理・海外離脱、年度更新/保存adapter、CPU人選/UIと本番接続は未完了。全信頼履歴を同時に書き換える攻撃の暗号認証はしない。JSONの合成state検証は本番保存移行や実iPhoneでの長期受入の証明ではない。

作業環境には旧ソースZIPしかなかったため、GitHub connectorで最新mainの実行source/設定/対象docsを取得しGit blob SHAで照合。lockfileどおりoffline npm ciで依存を構築。バイナリE2E fixtureは取得しておらず、ローカルE2Eは未実行。完全なGitHub checkoutによる同一公開headのCIを品質ゲートとする。最終ビルド・独立レビュー・CI・公開headは対象PR本文を正本とする。

独立レビューの判定対象外は、計画どおり後続の本番adapter/CPU/UI/保存移行/年度更新、規約の法的な現行性、暗号的な全履歴同時改変防止、未実行のブラウザ/全CI。前者は合意済み後続範囲、規約は上記一次資料を作者が確認、暗号認証は明記した限界、全CIは同一公開headで別途確認する。いずれも完了認定へ混ぜない。
