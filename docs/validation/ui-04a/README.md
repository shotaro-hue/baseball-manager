# UI-04A 検証記録

実施日: 2026-10-19。基準main `3f8f414d9e5d35938b21dc33b607379e5e2f26a2`（#481マージ済み）。[要件・工程別完了条件](../../implementation/ui-04.md)／[実装計画](../../superpowers/plans/2026-10-19-ui-04a.md)。独立PRのheadとCIの確定結果はPR本文に記録する。

## 実装範囲

- 主分類をホーム/編成/日程/成績/経営へ統一。PC・スマホは同じ定義を使用。
- 経営の概要/補強/契約/財務。概要・補強トップは既存機能へ移動できる暫定入口。予算は実stateを表示し、給与前利益や現金と混同しない。
- 全9機能を移設。通知入口は未読と要対応を別表示し、既読の未解決提案を保持、配達前メールを除外。一般ニュースの既読データは存在しないため生成しない。
- 通知/設定/選手詳細からの外部遷移には元画面へ戻る入口とブラウザ履歴を接続。隠した元本文は保持し、FAフィルタ・選択・フォーカス・スクロールを復元。
- メール→既存トレード画面へのリンク。受信箱の選択をIDで保持し、外部画面で解決したメールは実mailboxの状態を表示。UIだけで成功扱いにしない。
- 編成エラーは閲覧を妨げず、試合開始時の検証を維持。保存状態は全ヘッダーで既存の実保存追跡を使用。

財務本体・契約/補強本体・受信箱/ニュース/OB本文のDES-01移行、FIX-M2、旧セーブ移行、給与/CPU/取引ルール、保存スキーマ変更は含めない。
