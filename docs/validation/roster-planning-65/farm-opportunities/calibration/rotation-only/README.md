## 原因の切り分け

`active-bench-run.json.gz` は seed20261015 の実hookを5年再実行した診断。`active-bench-probe.json.gz` は元関数をそのまま呼ぶ観測で、乱数や選考を置き換えていない。全5年の試合・工程・判断データが完走10年の先頭5年と完全一致することを確認した。

`active-bench-review.json` に健康・所属・出場と年初の `managementMeta` をまとめた。2029年は前年度の `lastRosterDay:141`／`lastLineupDay:143`、2030年は142／138が残り、年度内日数との差で判定する通常の14日・方針別見直しを止めていた。次の修正版では年度更新の保存候補で両カウンタだけを0へ戻し、元の見直し間隔を回復させる。

`single-year-zero-*` は別の単年0（2028年 `299vk0p`）の3年診断。健康11日・負傷132日、翌2029年は一軍431＋二軍76打席。元の10年prefixと一致し、長期連続0と区別する。

`diagnostic-runner.test.js.txt` と `diagnostic-config.mjs.txt` は診断時の観測コード。`OPPORTUNITY_PROBE_ID`／`OPPORTUNITY_PROBE_SEED`／`OPPORTUNITY_PROBE_YEARS` で対象を指定し、`ROSTER_LONG_BASE` と `ROSTER_LONG_EVIDENCE` を明示して実行する。

`unused-policy-proposal.test.js.txt` は、原因確定前に検討した「実測出場0の一軍控えを定期入替する」未実装案。REDログ（2失敗・5成功）と期待値をそのまま保存した。新しい入替例外を追加する前に、既存周期の年度持越しを直す方針へ変更した。既存回帰テストは削除・skipせず、最終長期検査でも**途中年を含む複数年連続0を許可しない**。

これはこの校正時点の判断である。その後の[年度周期修正版](../cadence-only/README.md)でも健康な控えの連続0を確認したため、保存した案を回帰テストとして復活・拡張し、定期レビューだけの限定交換を追加した。未実装案の元の期待値・REDログも本フォルダに残している。
