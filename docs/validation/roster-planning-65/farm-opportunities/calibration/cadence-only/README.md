## 確定した原因

seed20261017 の `lkl85m9` は2031年 team7 の3巡指名、一塁手。2032年は二軍298打席だが、2033・2034年は一軍の控えに残って一二軍とも0打席だった。

同じソースの9年診断は完走し、全試合・工程・判断が元の10年実行の先頭9年と完全一致。`active-reserve-probe.json.gz` は元の関数・乱数を変えず日々の状態と実際の定期レビューを観測している。

|年度|健康日|一軍所属日|二軍所属日|実際の定期レビュー日|一軍打席|
|---|---:|---:|---:|---|---:|
|2033|143|143|0|14,28,42,56,70,84,109,138|0|
|2034|143|143|0|14,28,42,56,70,84,98,112,126,140|0|

年度周期を戻しても、通常の「二軍側が十分に強い場合だけ入替」の条件では、評価の高い控えを二軍へ戻す経路がない。DH込み9人を通常入替から保護する条件もある。定期レビューを通っていなかった、負傷していた、という説明ではない。

次の修正では、通常推薦後に実測出場のない控え1人を交換する限定ルールを追加する。両DHモードの8守備先発・捕手・登録資格・使用済みIDを保護し、捕手同士／非捕手野手同士の枠で交換する。通常評価差・人数・成長・給与・契約の定数は維持する。
