## 記録の意味と不足

- 支配下・投野・主捕手・守備位置、指名数/拒否/明示終了理由、67人超の評価、FA数/理由/年俸、予算/給与、出場と人員異動は`long-run-summary.json`の`perSeed.annual.clubs`。全工程と全選手の値は各圧縮原本。
- CPUの入団拒否は前後とも0。自球団の拒否は変更前3／変更後13（CSV参照）。CPU拒否の自然発生を長期検証で実行したとはしない。拒否時の枠留保は対象回帰テストで確認。
- 明示終了フラグがないCPU年度は前288／後285。`endReason: null`を後付けで「枠満杯」と断定しない。人数・指名数は全年度記録されているが、全停止理由の完全記録にはハーネス追加計測が必要（P2、次の校正で改善）。
- 変更前FA理由は未記録。変更後CPUのFA理由は全216件記録。個々のFA入札時点の残り新人予約人数・予算は原本へ逐一保存していないため、動的予約の正確性は人数推移に加えFA連続獲得・不足例外・最低新人年俸の単体/統合試験で補完する（P2、全入札監査は次工程）。
- 育成昇格は自然発生0。両育成フラグの別計上・手動登録・予定の消化は回帰テスト/E2Eで補完。長期で昇格経路を通ったとはしない。
- `playerUsage.current`は既存診断の**捕球能力**。ドラフトの観測現在評価や総合能力ではない。これから打力の停滞や成長不全は断定しない。
- 一軍球歴は年度更新前に既存の記録対象となる継続所属者全員の年度集合と照合。二軍のみの年度を架空の一軍球歴へ追加しない。二軍アーカイブ・年次履歴・保存再開の継続性は別に検査した。
- ポストシーズン大会を迂回。大会UI・優勝収益を含む完全App10年旅程、実機Safari、最終指名コホートの翌年は未検証。初期所属・RNG/ID消費が変わるので、同一選手や勝率の厳密な対比較ではない。
