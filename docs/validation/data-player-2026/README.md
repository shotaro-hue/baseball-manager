## 訂正・改善

- 福島圭音：支配下移行3月30日。平山功太：4月6日。開幕時点は育成とし、新規ゲームでは二軍へ置く。
- イヒネ・イツア、ワォーターズ：国内高校経由のドラフト入団を確認し、カタカナ名による外国人扱いを訂正。古林睿煬：台湾から2025年NPB加入の外国人枠判定漏れを訂正。この3名は生年月日・投打も公式プロフィールから確認。
- 旧データの外国人フラグは明示値へ凍結。新規入力に名前正規表現を適用しない。未確認の他選手の資格を確認済みと扱わない。
- 初期能力は2023–2025年の履歴を1/.65/.35の重みと事前分布で評価。2026年成績と昔のキャリア最高盗塁数を使わない。観測履歴とゲームの推定能力を分離し、実績なしでも偽成績は作らない。
- 正確な投球回は `outs`（整数）を受け付け、ゲーム境界で `outs/3` へ変換。既存の端数を失った履歴は逆算して捏造しない。
- 打者の投打、確認済み副守備位置、契約終了年を維持。未確認の汎用「内野手/外野手」はゲーム用配置であることを区分する。実際の全守備適性の精査は未完了。
- 給与欠落時の500万「万円」という単位不整合を廃止。必須値は既存の支配下420/育成240万円をゲーム用代替として使用。既存5000万円の曖昧値73名は真値へ書き換えず、未確認のゲーム設定と記録・表示。
- 履歴行数や乱数からFA日数を作らない。開始前の日数不明はゲーム用開始残高0とし、選手詳細で明示する。これは実際のベテランのFA資格再現ではなく、正しい日数投入までの制約。
- 正規化済み完全マスタは架空補充しない。不完全な旧マスタでは既存の人数・守備補充を残す。育成を支配下70枠や一軍へ数えない。
- `fetch-spaia.cjs` は明示した新規ステージング先だけに出力。既存ファイル・ソースディレクトリを上書きしない。
