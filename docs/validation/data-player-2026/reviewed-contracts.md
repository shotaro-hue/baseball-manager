## 主な訂正と採用基準

- **徐若熙・宋家豪・林安可**：標準版の外国人フラグをfalseからtrueへ。漢字表記に依存した漏れを修正。国内FA資格のあるビシエド・ソト・モイネロの枠除外を維持する。
- **モイネロ・R.オスナ・スチュワート**：総額からの年平均10億・10億・7億円は `gameSalaryManYen` とし、2026年の実額を確認したとは扱わない。契約期間とは別の確度で保存する。
- **有原航平**：移籍前の6億円規模という見積もりに対し、2026-01-13入団会見の複数報道の年俸5億円を採用。2月7日更新の移籍一覧も4年20億円規模を支持する。出来高を基本年俸へ足さない。
- **桑原将志**：新契約の年俸2億円。旧球団の1.2億円を採用しない。新しい複数年契約の正確な終了年は不明で、ゲーム上の2027年終了を明示する。
- **伊藤光**：2025-12-11の入団会見記事で2026年俸5,000万円を確認。前年の5,200万円と区別する。
- **牧野憲伸**：育成契約時の300万円ではなく、開幕前の2026-03-20支配下転換時の420万円を採用。
- **冨士大和**：開幕前の支配下転換後の年俸を確認できず、旧育成契約280万円を「開幕時確認済み」とする候補から除外。最低額への補完はゲーム設定のまま。
- **林安可**：2026–27年の契約と2028年の球団オプションを区別。オプション年を保証期間へ加えない。
- **陽柏翔**：国内扱いとの説明と在学期間の報道が食い違うためunknownへ。ゲームでは国内扱いを継続するが認定済みと表示しない。エミールは球団スカウトの国内扱いとの発言を根拠に記録し、細かな在学期間認定は未確認とする。

年俸のある年の契約更改だけでは単年契約と断定しない。過去の成績年数からFA日数・在籍年数を作らない。2026年開幕後の成績・為替・契約更改を初期値へ混入させない。日付付き原記事に対応できない年度別年俸表147人、旧育成契約1人、未確認新人15人の候補は別管理し、確定欄へ入れない（候補集合は相互に重複し得る）。

## 実装・更新手順

- `playerMaster2026.reviewed.json`：基準日付きの数値・契約・枠資格の訂正台帳。sourceに `knownBy` / `publishedOn` / `dateEvidence` を分離し、salary / contract / foreignQuota別の出典を要求する。
- `reviewedPlayerFacts.js`：安定IDと旧IDの一意性、球団、金額、年度、将来情報、項目別根拠を検査。給与・契約を独立したグループとして更新し、旧契約のオプション等を混入させない。
- `playerMaster2026.js` / `assemble.mjs`：同じ台帳を標準版の新規ゲームと完全名簿候補の双方へ接続。`npb2025.js` は直接上書きしない。
- `realplayer.js`：開始時の金額・確度・契約年・出典を `openingContractEvidence` として保持。ゲーム内所有IDは従来のuidを使用する。
- `PlayerModal.jsx`：ゲーム上の仮契約期間を明示。ゲーム内で契約・給与を変更した後に旧年俸の「報道推定」ラベルを引き継がない。

既に検証した開幕マスタの項目訂正は、次のCLIで別の新規ファイルへ行う。

```bash
node scripts/player-master/apply-reviewed.mjs \
  --input=/path/to/verified-opening-master.json \
  --output=/tmp/opening-reviewed.json \
  --report=/tmp/opening-reviewed-diff.json \
  --local-import
```

`--local-import` は明示した非同梱ファイルの検証モード。省略時は公開利用条件の検査を要求する。元マスタのverified状態、全属性・成績の検査、人数・ID・所属・登録区分の不変を確認する。任意の `--reference=` には別途検証済みの名簿だけを渡せる。未検証の公示抽出候補を渡すと拒否する。`--journal=` に別の明示した訂正台帳を指定できる。既存ファイル・src・git配下を出力先にできない。

## 残項目とマージ判断

年俸257人、終了年1,002人はゲーム用代替値。特に終了年には未公表の複数年契約を含み、契約日程・出来高・年ごとの変動額・保証条項を完全再現していない。FAの開始前登録日数は未収集で、ゲーム上の0日開始を維持。新人・海外・二軍実績や詳細守備適性の評価は今回追加していない。
