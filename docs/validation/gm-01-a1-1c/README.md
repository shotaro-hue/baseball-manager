## 実装

- `quoteAnnualBudgetPolicy(world, policy)` は非変更の見積。給与前の運営差額観測列、支援額、前回承認額（未記録は明示null）、配分率、平滑化年数、増減上限を必須入力とする。旧budget/nextClubBudgetは使用しない。負の運営差額は配分原資0とし、整数万円で切捨て、明示した前回承認額の上下限内へ制限する。
- 対象はbudgetSeason〜max(台帳・提示の終了年,budgetSeason+7)。承認・根拠・65人の資金計画を同じ範囲で生成する。65は登録下限ではない。生成policyは根拠と承認額を再検証し、最終年の行欠落を拒否する。以前の明示fixture policyは維持する。
- policy係数/予測値に本番既定値はない。将来の行は支給保証ではなく審査用見込み。年度境界でのreceipt、採用、春への接続はTask 10、校正はA1-4a。
- `spending.renewalPlans` は元契約/選手/球団/翌年度/予定額/basisの観測計画。正式な更改提示・確定契約が同じ年度を担う場合、計画は証跡として残し課金だけ止める。取消で再び計上する。所有が移った旧球団の計画は非活性となる。計画は移籍する契約債務ではなく、獲得球団の新たな計画は後続の計画生成側が決定する。
- 最低人数の費用では、計画で資金を確保した支配下選手を一度だけ数える。育成は支配下の不足人数を減らさない。正式留保・給与・保証・計画・スタッフ・一時費用は別区分。計画が復活する取消は新規支出ではなく、既存赤字例外で許可する。
- スタッフの正本は`contractEconomy.staffContracts`。行は`{id,teamId,season,role,annualSalaryManYen}`。年度担当と同一スタッフの年度重複を拒否し、同じ球団年度の旧coach一時費用との二重計上を拒否する。spendingには一時投影だけを渡し保存しない。通常の契約取引でスタッフ年度費/未更改計画の根拠を変更できない。雇用・解任UIはTask 8。
- FAの行使歴不明は`exercise:'legacy-conservative-max'`を明示し、初回率相当の最大補償を使う。初回という履歴を作らず、既知first/repeatは維持する。旧セーブへの自動推定・移行公開は行わない。

取消の例外が将来の計画額増加にも適用されるケースも追加RED。例外対象を「取り消した正式提示が押し出していた、旧台帳での計画額」に限定し、転換等の増加へ流用しない。Critical/Minor指摘なし。
