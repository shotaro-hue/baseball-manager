## 固定条件の校正

12球団×8条件=96シーズン。実際の2026年日程と本番の収支/予測関数を使い、人気・勝率・価格・改修を固定。試合、成長、契約、CPU編成は実行しない。全ケースで年度契約・費用・内訳和と予測の最終一致を確認した。[全結果](./fixed-scenarios.json)。

低価格では満員でも運営差額が赤字となる。動員最大化を利益最大化と同一にしない。上記は給与を含めない値で、実在球団の利益やゲーム内の現金残高ではない。現行の完全日程は69〜74主催試合のため、その実数を使用した。

動員基準のみ[NPB公式2025年平均](https://npb.jp/statistics/2025/attendance.html)を採用。商業契約・来場単価・経費はゲーム推定値。[日本ハム2026年3月期ボールパーク事業決算](https://www.nipponham.co.jp/corporate/ir/library/accounting/pdf/2026/20260508.pdf)は非試合日事業を含み、球団単独売上に一致させる資料として使わない。
