# 編成配分の固定行動感度分析

2026-10-26、main `677c14fb5f96723846d01d0f72c25ac6a0d651b7`（#503）。[設計案](../../superpowers/specs/2026-10-26-budget-allocation-design.md)の候補比較用。製品コード・依存・セーブは変更せず、既存原本から予算だけを計算した。

## 方法

#503の3seed×10年、CPU11球団×30年＝330球団年度を使う。支出と移籍・契約・給与・人気・成長・試合結果は固定する。翌年度係数を変える候補では、直前年度の実運営差額と翌年の実年俸を現行の下限/基礎予算へ適用する。初年度予算は全候補で元の値を保持する。

市場終了時点の投影は「元の市場残枠＋年度初予算の差＋新率で丸めた当年累積運営差額−元の当年運営差額」。丸めはJavaScriptのMath.roundと同じ向き。現状の係数で、全330件の年度初/市場残枠が原本に完全一致することをassertした。

## 結果

| 候補 | 翌年度係数 | 当年度配分 | 市場残枠 中央値 | 最少 | 50億円以上 |
|---|---:|---:|---:|---:|---:|
| 現状 | 60% | 100% | 76.31億 | 17.90億 | 268/330 |
| 年度初のみ | 30% | 100% | 63.49億 | 14.82億 | 238/330 |
| 当年50% | 60% | 50% | 54.39億 | 10.73億 | 192/330 |
| **当年25%（初期推奨）** | **60%** | **25%** | **43.65億** | **7.15億** | **129/330** |
| 両方・当年50% | 30% | 50% | 43.15億 | 7.66億 | 129/330 |
| 両方・当年25% | 30% | 25% | 32.11億 | 3.65億 | 67/330 |

全候補の投影市場残枠は負値0。ただし、採用後のCPU再判断・シーズン途中の資金ショート・主力流出・利用者の球場投資を実行した結果ではない。50億円以上という列は資金の水準であり、実際のLv3改修可否・契約を残す安全額を保証しない。各選択の控除時点も変えていない。

[sensitivity.json](./sensitivity.json)に内部単位万円での最少/中央値/平均/最多・年俸比・各金額帯と入力/解析コードSHA-256、[frozen-candidates.csv](./frozen-candidates.csv)に6候補×330＝1,980行を保持する。固定行動の参考計算であり、新しい10年プレイの合格証跡ではない。

## 再現

```sh
python docs/validation/budget-allocation-design-20261026/frozen-sensitivity.py
```

原本は`docs/validation/cpu-finance-long-20261025/seed-*.json.gz`の完全な年度JSONを使う。欠落のある補助JSONLを集計元にしない。自球団の信頼度・投資・任意取引、プレーオフ/賞金、日中の流動性、実端末の容量/速度はこの試算に含まない。
