## 判断

人数の事前目標を合否にしていない。67人は138/330、68–70人も120/330あり、上限への一律張り付きと無条件指名の双方を避けている。指名0の6年度は全て67–69人で既存の例外基準を満たさず停止した。9人指名は1件 (seed15/2027/team2)、64人終了も1件あり、毎年固定人数へ揃えていない。各seedの70人は94→6、84→4、95→6、最長指名0は4→1、3→1、3→1と同方向に改善した。

放出1,201件は実新人との更新比較、実戦の主力・若手・必要な層の保護を通った判断で、年齢だけでは決めていない。市場獲得も増えており、年俸平均は約1.7%増、予算平均は約0.4%減。若手比率は上がる一方で35歳以上も6.68%残り、最終年度まで年齢は上がる。世代交代の改善は確認できるが、最適な年齢・異動頻度の保証とはしない。捕手上限9・投手上限38は過剰層の余地として今後も監視する。

捕手6人は補強完了/翌開幕の組織基準。退団・移籍による途中不足まで0とは主張しない。実測では更改直後の最少4 (基準2)、市場終了時5 (基準5)、シーズン終了時5 (基準5)。翌開幕は全CPU6人以上、他の各主守備位置も2人以上、二軍858カード/年は全て成立した。常時6人を保証する移籍・退団制約はこの変更に含めていない。

## 検証の範囲

ポストシーズン大会と賞金は両側で迂回し、完全App10年とは呼ばない。候補の前倒し生成と交渉対象の差で乱数順が変わるため、同一選手・勝敗・時間の対比較ではない。最終年新人の翌年は未観測。全球団の所属・契約・異動履歴は保存checkpointで検査するが、最終球歴DBの再読込は自球団継続所属の実期待年度を対象とする。ブラウザE2Eは実際の更改→市場終了→自動保存→再開も検証する。実機Safariは対象外。
