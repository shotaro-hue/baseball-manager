# AI-03 検証記録

基準: #479 merged / main `270edd8286762c1de5949953e1887bdb286e36ee`。

正式比較の完了前。3seed×10年、各330 CPU球団年度を同条件の独立ジョブで比較する。

`scripts/run-ai03-long-run.mjs`はソースと実行環境を固定し、原子的な年度JSON、各判断JSONL、Vitest JSON、実プロセス終了記録を残す。`scripts/summarize-ai03.mjs`は全6本の完走と最終球歴assert、固定ソースtarのhash、143試合/実二軍、保存再開の存在を検査し、分布・指名・年齢・異動・出場・捕手/各位置・財務を集計する。

人数の任意目標を合否にせず、70上限、必要捕手/各位置、予算負値、二軍未実施、複数年無出場を安全条件として検査する。70人率や指名0継続は改善前後の実測を評価する。

校正・中断・失敗は`calibration/`へ保持する。校正の完走を最終版の完走へ読み替えない。
