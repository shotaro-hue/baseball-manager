# A1-2c-2b 期中解雇の検証

基準main: bd73308a00fbfda9c9cfd875e78c96e7e114ba94（#538マージ後）。

## 対象と正本

v2/season の enter-market/releaseを既存の冬の退団取引に追加する。worldの契約時計とgameDayを使い、gameDayは一時投影のみ。所属を削除した後の保有選手で両軍を成立検査し、証明用配置を採用しない。選手の能力、残る選手の一軍/二軍配置と待機を維持する。解雇を理由とする新たな10日待機は設定しない。

雇用は当日で終了し、支払・保証残額は既存台帳のretainで保持する。元契約単体の通知日雇用から退団証跡を検査し、再雇用後に旧契約を全台帳へ復活させない。市場・履歴・留保取消・receiptを一つの候補で更新する。人向けpending更改と受諾済み将来契約は拒否する。
