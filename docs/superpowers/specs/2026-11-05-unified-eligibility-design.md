# ポスティング・FA資格の統合設計

依頼書の確定方針を実装する。ユーザーが指定した監査→設計→RED→共通処理→データ/保存→GREEN→CI→独立レビュー→文書→PRの順で実行する。追加の仕様承認は要求しない。

## 監査と依存

- main `9ea1468f1f45e5dda97c7db16e16d5d1bb00715e`。#546/#547はマージ済み、#548は未マージ、HEAD `7758f6d87ce5c7edb8d8d36cd233ba3969697bff`。元PRを変更せず、そのHEADから専用ブランチを作る。提出PRのbaseはmain、依存を明示。
- 実名簿1,059人、全員birthDateあり。登録日数/serviceYearsは未記録、entryTypeは多数が不明。draftYear/entryRouteは固定NPB IDへ結合済み。最古成績年をプロ入り年と同一視しない。
- FAは現在120日換算。getFaProgress以外にCPU更改、人更改、海外離脱の直接判定がある。日次処理は毎試合+1、年度処理のserviceYearsは別の既存意味を持つ。
- v2のFA宣言は選手snapshot・資格結果・行使回数・receiptを保全するが再取得残高へ未接続。#548は保存済み資格検証にも現所属を要求するため、作成時の所有検証と歴史検証を分離する必要がある。
- schemaVersion1/DB5・公開ゲートOFF・元契約/予算/RNG/保存identityを維持。初期データ補充は新規ゲームのみ。保存された過去の資格結果を再計算し直さない。

## 採用方式

既存値の一括単位変更は旧保存と署名を破壊する。日数だけの修正では初期欠損と行使後の再取得を解決しない。このため選手にversion付きeligibilityを追加し、旧フィールドを維持する方式を採用する。

- proStartYearとbirthDateを初期化時に固定。公式のドラフト/入団情報を優先し、欠損は入団区分・保有履歴等から明示的なゲーム推定。海外の初回契約を確認できない場合も推定と明記する。架空の新人は最初のプロ契約の入団シーズンを使用。
- professionalYears = max(0, completedSeasonYear - proStartYear + 1)。completedSeasonYearを明示し、シーズン中に当年を先取りしない。25歳以上かつ6年以上ならexempt、それ以外restricted。新snapshotはruleVersion2、旧ruleVersion1を歴史専用として維持する。
- 新FAは145日基準。高校等8年、2007年以降のドラフト大卒/社会人7年、海外9年。区分未確認は年齢から学歴を捏造せず、明示的な「その他」ゲーム設定で8年。行使後NPBへ再契約した選手は4年=580日で海外FA再取得。
- FA初期残高は公式資格そのものとは別のゲーム推定。公式の取得済みフラグを残高不足で取り消さない。2025有資格名簿と2025までの行使公示を固定IDで照合し、2026-03-27以前の契約だけを扱う。公式資格から正確な日数を作らない。
- 非公式サイトは利用条件/取得時点が未解決のためデータ取込を行わない。内部計算はネットワークへ依存しない。
- 143ゲーム日のd番目に floor(d*145/143)-floor((d-1)*145/143) 日を加算。一軍登録のみ、年別の処理済みゲーム日を選手に保持し、移籍をまたいで重複を除外。シーズン145日上限。端数は通算へ保持。怪我でも登録中は加算、二軍/抹消中は加算しない。
- 旧120日保存は元値を残し、新残高へ明示的に145/120倍で移行。欠損0と実測0を区別し、未記録だけ履歴による推定を使用。移行は冪等。新規マスタの最新公式情報を旧保存へ注入しない。
- 全呼出元は同じgetFaProgressへ接続。旧FA宣言の保存資格は従来計算を維持して検証し、新規宣言の選手にはversion2根拠を固定する。補償の行使歴と資格残高は区別する。

## 制度上の境界

FAの傷病特例、2020年短縮特例、補償、外国人枠は別制度。初期の公式資格には反映済みだが、新しい特例の自動認定は行わない。ポスティング申請/承認、市場評価、本人受諾、契約成立、退団は別のまま。市場接続は今回の対象外。

## 検証

実名簿/生成選手/旧保存を入口に、年齢・年数境界、資格閾値、公式104人/行使8人、未来情報拒否、143日完走、抹消/再登録、移籍/育成転換、行使後再取得、JSON/実保存復元、履歴改変拒否、保存失敗/回復を検証。既存検証を弱めず、変わる仕様の期待値だけ根拠付きで更新。CIはHEAD一致を確認する。
