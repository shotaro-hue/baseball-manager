# GM-01 A1-2b-4 旧スカウト直接獲得の終了・既存データ保全

承認仕様: 2026-11-02ユーザー要件。基準main `753adc5da2818432f96f4ace3466370d1af11db5`（#534マージ済み）。

## 目的と範囲

派遣費支払いで架空選手を生成し直接契約する旧経路を終了する。legacy / annual共通。
`sign-scouted`の新設、旧3秒通知の永続化、`send-scout / receive-scout`の接続予定は**方針変更により不要化**。実装完了とは記録しない。
新スカウト制度、A1-2c、annual一般公開には進まない。

## 振る舞い

- `sendScout` / `signPlayer`は互換APIとして残すが、常に`false`を返す。通知・タイマー・名簿/予算/契約/市場/receipt/revision/dirty変更を行わない。古い参照・無効引数も同様。
- Routerから派遣・契約・候補削除の配線を外す。旧タブID `scout` は閲覧専用に維持する。
- `initDraftPool`は通常の160候補を生成する。旧`scoutResults`の自動取り込みは停止する。既に保存済みのドラフトプールや所属選手を遡って排除しない。
- 既存候補・派遣待ちを削除/移行/返金しない。派遣待ちはロード・時間経過・通常/Worker/年度進行で再開しない。
- 獲得済み選手のID・所属・登録/配置・能力・成績・履歴・年俸/契約・起用・故障を本変更を理由に変更しない。署名日や保証条件を補完しない。
- 保存schema / DB versionは変更しない。通常の主保存・バックアップ・保存競合・セッション保護を再利用する。

## 画面

記録なしでは通常の経営/補強導線に旧スカウトを出さない。旧タブ指定は終了案内と「補強トップへ」を表示する。
候補または派遣待ちがあれば「旧スカウト記録」を補助導線として表示する。要対応バッジを出さない。
候補の検索・絞り込み・詳細・比較は閲覧専用。派遣先選択・契約・削除・待機カウントダウン・成功通知はない。
派遣記録は「機能終了により停止」と表示し、過去の派遣費/獲得費の返金なしを説明する。

## 維持する機能と後続

ドラフトの生成/評価/指名、外国人市場の生成/交渉、FA/自由契約、新人/育成/トレード、通常の年度更新、既存能力評価を維持する。
コーチ・球場投資はTask 8へ残す。調査・評価の再設計は別工程。将来は選手供給と発見/評価を分離し、獲得は正式な既存経路に接続するが、具体仕様はここでは定めない。
Task 6全体およびA1全体は未完了。翌春加入・CPU・年度更新・移行・公開検証の残課題を維持する。
本工程のPR提示後はユーザーのマージ判断で止め、マージ後の次工程はA1-2cとする。

## 検証と限界

実hookで両modeのAPI拒否、保存前後の全対象state・dirty・進行token・保存領域非変更、古いcallback、タイマーなし、通常保存/再読込、欠落/空、保存失敗の保護を検査する。
UIとRouterで旧操作の不存在、記録の有無によるナビ、旧タブの復帰を検査する。
Chromium/mobile WebKitと360/390/1440pxで記録閲覧・一覧復帰・保存/再読込・停止中派遣を検証する。
143試合の既存旅程に旧候補/派遣を入れ、単試合/実Worker/CPU/年度更新/翌年初戦を通じた保全を検査する。

更新前のJavaScriptを実行中の別タブまで停止するものではない。既存の書込ロック、世代CAS、セッションtoken、保存version fenceを変更せず、大規模な旧クライアント排除は別課題とする。今回DB/schemaを上げないため、互換versionの旧クライアントがロックを取得して旧処理を実行する可能性は残る。
