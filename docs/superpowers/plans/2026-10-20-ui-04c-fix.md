# UI-04C-FIX Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** スマホの契約・補強一覧を軽量化し、探索・詳細・判断・復帰を改善する。
**Architecture:** 読取専用の一覧モデルと軽量行を共有。各画面の取引処理は保持し、詳細は選択後だけ生成する。
**Tech Stack:** React 18 / Vite / Vitest / Playwright / Chromium Performance trace。
**Spec:** `docs/implementation/ui-04c-fix.md`（ユーザーの実装指示に基づく）。

## Global Constraints

ゲームロジック、保存形式、金銭計算、CPU判断の変更禁止。mainへpushしない。マージ/自動マージしない。760/761・1023/1024境界を維持。既存確認/二重実行防止を維持。

## Review Focus

- 待機中メール/他年度メールの区別と契約件数の一致。
- 退団した通知IDで前に選んだ選手を表示しない。
- 詳細中に候補が削除されても別IDへ操作しない。
- 条件変更や候補削除後もフォーカス/スクロールを復帰。
- 非表示の保持済み画面が通知の案件フォーカスを奪わない。
