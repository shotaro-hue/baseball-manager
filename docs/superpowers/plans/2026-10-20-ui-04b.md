# UI-04B 経営概要・財務 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 編成予算・契約年俸・枠と対応待ちから次の判断へ進み、価格・球場投資を比較して明示確定できる。

**Architecture:** 既存の `HubManagementTab` と `FinanceTab` をDES-01へ移行する。収支計算は `forecastClubFinance` / `calcClubGameFinance` に委譲し、比較用のコピーと入力下書きだけをUIで持つ。年俸上位表示は契約へ移設する。

**Tech Stack:** React 18 / 既存DES primitives / Vitest / Playwright。

**Spec:** `docs/implementation/ui-04.md`（Bの実装基準・補足受入条件）、`docs/DESIGN_SYSTEM.md`。

## Global Constraints

- 基準main `64bda9741a31799280c159276c2138aa574a7727`。#483・#484マージ済み。工程1PR、main直接push・マージ・自動マージなし。
- 360/390/1440px、760/761・1023/1024px。操作44px以上、ページ横はみ出しなし。
- budgetは編成予算残枠。給与控除前の運営差額と契約年俸を区別し、年俸を予算から二重控除しない。
- 手動価格500〜5,000円、球場費用10/25/50億円。既存ハンドラ・保存形式・CPU判断・財務定数を維持する。
- UI-04C/D・旧セーブ移行・現金会計・架空の推移は対象外。既存互換表示は維持する。

## Review Focus

- 下書き中に最新予算・人気・日程が変わった場合、最新条件で再比較し支出を既存ガードで検証する。
- 入力空欄・範囲外・小数は確定せず理由を表示。0/負値/未記録/算出不可を区別する。
- シーズン末の残試合0でも通年比較は算出でき、実績を上書きせず参考回収年数を過大表示しない。
- 通知往復は同一年度の下書きを保持し、セーブ/年度切替で持ち越さない。
- 年俸上位の移設後も一軍/二軍/育成・欠測の詳細閲覧と保存前後不変を検証する。
