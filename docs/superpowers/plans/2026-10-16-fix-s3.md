# FIX-S3 OPS精度・表示整合性 実装計画

> 実行方法：このセッションで直接実装。ユーザーの実装指示書・AGENTS.mdの合意済み条件を適用し、再承認・マージは行わない。

**Goal:** 同じ一軍カウント成績のOPSを小数3桁で統一し、旧履歴とゲーム判断を保護する。
**基準main:** 5ec2e7672115bb2a4fac2f54a4c00b8818ff7fb1（#472マージ済み）。Git cloneとGitHub mainを照合。添付ZIPは不使用。
**Architecture:** 生のOPS計算を共通化しsaberBatterは最後にr3。CPUの2参照だけは生値から従来のr2を明示し、二重丸めを防ぐ。CareerTableのOPS読取は表示専用helperへ分離し、完全なカウントを優先・不足時は正の保存OPSを維持、通算は合算カウントから計算する。
**Tech Stack:** React / Vitest / Playwright。依存・CI・保存形式変更なし。

## 制約・レビュー重点
- mainへのpush、マージ、自動マージ、ゲームバランス・他指標変更は禁止。
- 元々compactCareerStatsが欠測を0にするため、旧実在選手履歴の一部はHBP/SFが本当に0か判別不能。PA内訳に未説明の差がある履歴は完全扱いせず保存OPSへ戻す。判別不能な履歴の精度を保証しない。
- 実測0／未記録／分母0、現在年度の部分欠損を区別する。描画時に保存値を書き換えない。
- 通算で一部年度が欠ける場合、欠測を0補完した確定OPSや年度OPS平均を作らない。
- 移籍の同一年別球団、ポスト区分、未取得詳細の注意表示を維持。
- CPUの丸め境界（例 .7946→.795→.80）で従来の判断を変えない。
