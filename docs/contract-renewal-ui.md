# 契約更改UI

個別交渉を基本に、スマホでは「対象一覧 → 選手との交渉 → 一覧へ戻る」、広い画面では一覧と交渉を並べて表示する。Calm Dugoutの明色と44px以上の操作部品を使う。

## 今回の範囲

- 対象者を画面開始時に保持する。複数年契約後・戦力外通告後も人数と結果を追える。
- 年俸・契約年数の下書き、提示回数、再交渉回数、交渉履歴を選手ごとに保持する。一覧に戻るとスクロール位置と選手ボタンのフォーカスを復帰する。
- 今季成績と契約条件を先に表示し、査定理由・能力・士気・信頼・保存済み年度別成績は展開する。年度別成績には既存CareerTableを使用し、保存済み詳細・通算・グラフへの入口を維持する。
- 要求年俸と合意判定はPR396の共通ロジックを使う。提示回数に伴う士気・信頼、FA資格、再交渉、1〜3年の選択を維持する。
- 戦力外は個別確認後に実行する。次へ進む前に合意条件・FA・戦力外をまとめて確認する。未合意が残る場合は次へ進めず、対象者への入口を表示する。
- 年俸総額は開始時の登録選手とfarmの年俸を基準に、合意額を反映した見込み。未合意は前年年俸、FA・戦力外は除外。複数年の総支払額や資金残高ではない。必要な年俸が欠ける場合は未記録と表示する。
- 実測値0と欠測を区別する。率は分母がない場合に「—」、未保存カウントは「未記録」。投手の奪三振はKpを使用する。

下書き・履歴はこの画面の滞在中に保持する。再読み込みをまたぐ保存は今回の対象外。

## まとめて提示・FA・減額制限

- Bとして任意の「まとめて提示」を追加。未合意の選手を選び、要求額／前年額の割合と年数で下書きを作成できる。個別編集した下書きも使用する。選手ごとの提示金額・年数・減額制限超過を確認してから各1回だけ提示する。結果は合意・不合意などを選手別に表示し、勝手に戦力外・自由契約にしない。
- 国内・海外FAまでの残り日数と最短年数を、既存の一軍登録120日＝1年の基準で表示。実際の登録日数0を維持し、旧データのserviceYearsからの推定は明記、両方なければ未記録。生成選手の「高校生」と旧データの「高卒」を同じ8年基準に統一する。
- 提示金額に前年年俸由来の入力下限は設けない。正の金額を提示できるが、支配下420万円／育成240万円のゲーム内最低年俸保障を下回る契約は成立しない。
- [選手会掲載の野球協約2025・第92条](https://jpbpa.net/wp-content/uploads/jpbpa-pdf/ag2025.pdf)：前年年俸1億円以下は25%、1億円超は40%。選手が同意すれば超過減額も可能。境界を100万円単位に丸めず判定する。
- 制限超過の同意は共通の契約条件・性格による合意判定で決める。不合意なら「減額制限の対応待ち」とし、制限内で再提示するか、確認して自由契約にする。FA権行使や戦力外と区別し、自由契約理由を市場・履歴・ニュースに残す。保留者名簿、公示期限、調停等の現実の全手続きは再現せず、手続きを選ぶ流れに簡略化する。
- CPUは同じ合意判定を使用するが、従来通り制限内から交渉を開始する。

## 確認

コンポーネントテストは下書き保持、ID 0、複数年契約後の親更新、戦力外確認と除籍後の結果保持、二重処理防止、再交渉履歴、FA、0と未記録、遅延ロードを検証する。

Playwrightの追加シナリオはスマホの一覧復帰・ページの横溢れと、確認ダイアログのフォーカス循環・Escape・背景スクロール抑止を対象にする。実ブラウザ実行と目視確認は未確認。

ユーザー確認事項：375px前後の画面で一覧と交渉を行き来し、年俸の編集・査定理由の展開・複数年合意・再交渉・年度別成績・戦力外確認・最終確認が読みやすく操作できるか。
