# オフシーズンの判断・結果画面

対象は引退整理、成長レポート、戦力外・自由契約整理、自由契約結果。既存のScreens.jsxからの公開名とフェーズ順を維持し、実装をOffseasonReviewScreens.jsxに分離する。

## 操作

- Calm Dugoutの配色、16pxの本文と44px以上の操作部品を使用する。概要を先に示し、成績・能力・選手詳細は展開する。
- 引退は判断待ち・引退予定人数を表示する。受け入れの判断は確定前に見直せる。一度行った引き留め抽選は保存し、再抽選しない。全候補の判断結果と登録人数を最終確認してから確定する。保存処理が失敗した場合は判断を保持して再試行できる。
- 戦力外はチェックで対象を選ぶ。選択時には放出せず、選手一覧・契約状態・放出後の登録人数・対象年俸を最終確認する。放出なしでも次へ進める。更改・FA補強時の契約年度を記録し、今オフ契約済みの選手を通常候補と分ける。残り1年以下の契約済み選手も展開領域から明示的に選べる。
- 自由契約結果は今回放出した選手について、他球団への入団と市場に残る人数を先に表示する。入団先・元の成績・選手詳細を保持する。
- 成長レポートは急成長・成長・下降の人数を先に示す。選手ごとの合計変化量、成長前の保存値と現在の能力値を展開できる。33歳以上・5pt以上の下降は起用を見直す候補として表示する。

## データと処理

実測0、欠測、算出できない率を区別する。能力の前後いずれかが欠測なら差を推定しない。レポートに記録されていない小さな変化・ファームの成長内訳は補完しない。未記録の成長／自由契約結果を「対象0人」と断定しない。

戦力外の対象条件（契約残り1年以下）、年俸による人気低下、予算返金なし、CPU交渉、獲得履歴を維持する。放出後の球団データをCPU交渉へ渡すように修正し、旧ロスターで放出が巻き戻ることを防ぐ。放出対象を打順・ローテーションからも外し、登録・履歴・市場・結果を同じ処理にそろえる。二重確定と消失・契約状態変更後の対象確定を防ぐ。

引退処理では数値ID 0を判断記録と照合できるように修正し、年度成績保存の選手IDにも0を保持する。引退タイプ0は欠測の既定値50へ置き換えない。引き留め確率の式と、0以外の引退判定を維持する。

試合、物理演算、先発／中継ぎ交代、給与評価、減額制限、FA資格、成長計算には変更を加えない。

## 確認

確認ダイアログはEscape、フォーカス制御・復帰、背景スクロール抑止の共通フックを使用する。成長の能力表だけ領域内で横スクロールできる。

自動テストは選択・取消・再確認・二重操作、今オフ契約済みの表示、対象変更、予算の欠測、引退判断・抽選保持・保存失敗の再試行、選手詳細からの復帰、成長値の欠測・0、放出後ロスターと履歴の保持を確認する。

目視確認・ブラウザE2Eは未実施。ユーザー確認対象は、スマホでの4画面、選手詳細への往復、今オフ契約済みの展開、確認ダイアログ、成長内訳の横スクロール。
