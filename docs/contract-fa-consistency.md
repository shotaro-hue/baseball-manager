# 契約・FAの整合性修正

対象mainは `89c19422f231a6517b8c4a9a78f9e24fbe6dd62d`（PR410取り込み済み）。目的は通常契約の拒否で所属が意図せず失われる経路を閉じ、ユーザーとCPUのFA獲得に同じ所属枠・配属ルールを適用すること。

## 通常契約と回答メール

- 登録・ファームの今季満了契約が対象。拒否・保留だけでは所属・現契約・編成・FA市場を変更しない。期限後の判断は既存のオフシーズン更改・FA・戦力外フェーズで行う。
- 合意は更改と共通のフィールド更新で、年俸・契約年数・残年数・締結年度を記録する。育成3年満了までの年数と最低年俸を確認する。減額制限を超える提示も合意でき、拒否メール自体を自由契約申請として扱わない。
- 正の提示額は最低年俸未満でも受け付けるが、最低年俸を満たさなければ成立しない。年俸0・非有限値・不正年数は受け付けない。
- 新しい提示には所属球団ID・提示年度・現在の契約状態を保存。再提示時は旧回答予定を取消済みにする。
- 回答時に所有・契約状態を再確認。移籍済み・別契約成立済み・条件変更済み・年度変更済み・不正条件の回答は適用しない。旧メールは可能な範囲で年度・所属・満了状態を検証し、回答または取消履歴として同じメールIDで保持する。旧セーブにない契約状態の履歴は捏造しない。
- 解決済み回答は再処理しない。同じ旧回答を再投入しても、当年締結済みの契約を上書きしない。二軍の選手とID 0も処理する。
- 契約タブの明示的な放出は既存の戦力外処理を使用し、所有配列・編成参照・履歴を整理して理由付きで市場へ追加する。拒否とは別の操作として保持する。

## FA獲得

- 一軍28人は登録枠、支配下70人は一軍＋二軍の所属枠として区別する。育成契約は支配下数へ含めない。
- 一軍満員でも支配下枠と予算に空きがあればCPUは二軍へ獲得できる。外国人枠・投打バランスによる二軍配属、育成の二軍配属もユーザーと同じ関数で判定する。昇降格は既存の編成自動化へ委ねる。
- 支配下満員の場合は双方とも支配下FAを獲得できない。育成契約の獲得は可能。複数獲得時は毎回最新の所属総数・予算を確認する。
- CPUは未記録予算・要求額、所属済み選手の重複獲得を拒否する。ユーザーにも所属済み選手と支配下満員の検証を追加する。
- 契約費用・CPUの予算留保・評価基準・宣言率・要求年俸・年俸精算時期は変更しない。したがって、今回の修正だけで市場に残る全選手が契約するとは保証しない。
