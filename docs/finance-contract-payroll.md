# 財務画面：選手契約年俸の表示仕様

基準main: `c39882596a8c7390f9ef2bb1d2f9066d7981c025`（#420〜425反映済み）。

## 目的と集計対象

現在の球団所属選手の契約年俸を確認する。財務画面の描画は選手、配列順、編成、予算を変更しない。

- 所属元は `team.players`（一軍）と `team.farm`（二軍）。育成選手もこの配列に含まれる。
- `育成` フラグを最優先し、一軍支配下・二軍支配下・育成のいずれかに一度だけ計上。
- IDがある場合はIDで重複除外（ID 0も有効）。一軍→二軍の順で最初の記録を使用。重複した記録の年俸や属性が異なる場合も、一軍側の記録を表示上の基準とする。元データを修復しない。
- ID未記録の別オブジェクトは別選手として扱い、同じオブジェクトが複数回登場する場合のみ重複除外。ID欠落自体の修復は対象外。
- FA市場・未契約スカウト候補は対象外。契約残年数によるフィルタは設けず、所属配列の現状を表示する。
- 空の区分は0人・0万円。旧保存データのfarm未定義は空配列として扱う。

## 金額・未記録の意味

金額の内部単位は万円。既存 `fmtSal` で表示し、億円表示の丸めも維持する。
「選手契約年俸（年額）」は契約額の合計であり、予算から控除した支払済み額ではない。
内訳の生の金額の合算と合計は一致する。既存fmtSalによる各行の丸めで、億円の表示文字列の足し算に丸め差が出る場合はある。

| salary | 扱い |
|---|---|
| 有限の数値、0以上 | 確認済み。0も有効 |
| undefined / null | 未記録 |
| NaN / ±Infinity / 負数 / 文字列 / その他の型 | 不正値。型変換しない |

欠損・不正値がある区分と合計には「確認済み X（集計不完全）」、該当人数を表示し、合計が確認できた年俸だけである旨を説明する。欠損を0として断定しない。

年俸上位は同じ重複除外後の所属選手の上位6人。確認済み額の降順、同額は元の所属順（安定ソート）。未記録・不正値は確認済み0より後ろに置き、空きがある場合は状態ラベルで表示する。区分・守備位置・契約残年数を併記。選手名ボタンは既存の詳細callbackへ元の選手オブジェクトを渡す。詳細画面の年俸表示にも同じ判定を適用し、未記録・不正値で描画を失敗させず、選手データを補正しない。

## 状態・描画経路・保存

`contractPayroll(team)` は副作用のない算出関数。新しい配列だけを並べ替え、選手オブジェクトを書き換えない。集計値を永続stateへ保存せず、毎描画で現在のteamから算出する。昇降格では内訳だけが変わり、契約変更・獲得・放出では差額が反映される。

モバイルは下部メインメニュー、PCは監督メニューから「その他→球団運営」を開く。いずれもHubShell→HubContentRouter→同じ遅延読込FinanceTab。年俸表示CSSは `.finance-payroll` に限定し、PCでの既存の幅＋paddingのはみ出しは `.hub:has(.finance-tab)` のbox-sizingだけで対象タブへ限定して補正。360px/390px/1280pxで同じ固定保存データを比較する。保存API・形式・IndexedDB構造に変更なし。

## 今回変更しない未解決課題

- 年俸の支払時期、契約時・年度更新時の予算控除。SPEC.mdの支出タイミング表は過去資料で、現行精算ロジックを今回検証・認定したものではない。
- コーチ継続給与、出来高、タイトル賞与、オプトアウト精算。
- 本拠地／ビジター収入、年間収入予測、球場投資の単位・費用と表示の整合性。
- 契約評価式、ゲームバランス、他画面の集計、財務の全面刷新。

コーチの金額は既存の参考値を維持し、精算・支払の修正とは扱わない。これらの課題は本PRで解決した扱いにしない。
