# FA・自由契約市場の画面

Calm Dugoutの配色と44px以上の操作部品を使用する。スマホでは候補一覧から条件画面へ切り替え、一覧へ戻ると絞り込み・並び順・スクロール位置を保持する。PCでは一覧と条件を並べる。

## 判断から契約まで

- 予算、登録人数、外国人数、市場人数を概要に表示する。
- 補強ポイントは展開して確認する。先発4・中継ぎ3・抑え1は登録人数、捕手は既存定数の登録2・登録＋ファーム3を目安とする。能力や将来性の推定値ではない。
- 市場種別、投手／野手、選手名で絞り込み、年俸・年齢で並べ替える。
- 候補の保存された成績、選手詳細・年度別成績、共通の選手比較へ進める。比較対象にID 0も使用できる。
- 年俸、年数、総額、契約後の予算、配属予定を表示し、確認ダイアログで確定する。
- 完了後も条件と配属先を表示し、編成での次の操作を案内する。
- 外国人交渉の最新返答を表示し、履歴は展開する。候補を切り替えても交渉を保持する。再交渉は明示的な操作で始める。

## 維持するゲーム内ルール

- 国内FA・自由契約の年俸は固定。契約年数は1〜3年。
- 外国人の希望年俸は現年俸×1.2の切り上げ。希望条件は受諾でき、現年俸での交渉の受諾確率は従来の55%。30歳以下は2年、31歳以上は1年。
- 外国人補強は第100日まで。国内の契約にはこの期限を適用しない。
- 年俸×年数の総額を契約時に予算から差し引く。
- 登録28人、外国人4人の枠が満員の場合はファームへ配属する。外国人の4人目が全員投手または全員野手になる場合もファームへ配属する。
- 獲得履歴、自由契約由来の履歴区分、契約年数・残年数を維持する。
- 要求年俸算出、契約更改・減額制限、FA資格、表彰、試合エンジンは変更しない。

## データと確定処理

カウントの実測0を表示し、欠測は「未記録」、計算できない率は「—」とする。予算・年俸の欠測から無料契約を作らない。年俸0も表示は0のままにし、契約は無効とする。

確定時に市場への在籍、予算、外国人期限、年俸・年数を再確認する。連続タップによる重複契約と、親の予算更新が反映されるまでの二重使用を防ぐ。

確認ダイアログにはEscape、フォーカス制御・復帰、背景スクロール抑止の共通フックを使用する。獲得済みで候補ボタンが消えた場合は一覧領域へフォーカスを戻す。

## ユーザーによる目視確認

目視確認は未実施。スマホ幅で候補一覧・絞り込み、条件画面、比較、最終確認、予算不足、期限終了、ファーム配属、契約後の一覧復帰をご確認ください。
