`des01_*` は全文PNG、`viewport_*` は360×800／390×844の初期表示。PC全文は幅1440px。選手名・人数・年俸・成績はサンプルであり実データではない。画面ごとに独立した表示状態で、参考二軍画像の再実装でもない。
