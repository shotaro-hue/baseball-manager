# プレーオフの勝敗・終了判定（2026-10-07）

## 目的と対象

引分を敗戦や勝利へ変換せず、1試合ずつ／まとめてシム／保存再開で、出場球団・勝数・終了条件・開催地を一致させる。最新main `69b178644a030aeeaab4c026296dac0a0fbb7a29`（PR411マージ済み）を基準に実装。Sitesと添付ZIPは使用しない。

## 規定と根拠

- [2026年 セ・パCS規定改定](https://npb.jp/games/2026/info_cs.html)：ファーストは最大3試合、先に2勝。通常ファイナルは最大6試合、1勝のアドバンテージ込み4勝。2026年以降、1位と実際のファースト勝者の差が10ゲーム以上、または勝者の勝率が5割未満なら、最大7試合・2勝のアドバンテージ込み5勝。双方が先勝条件に未到達なら勝数の多い球団、同数ならシーズン上位球団。上位球団が残り全敗でも同勝数以上となった時点で終了。アドバンテージは合計勝数に含め、実勝数と表示を分ける。
- [2026セCS開催概要](https://npb.jp/games/2026/info_cscl.html)：CSは延長12回。同点で上位球団の進出が決まる場合、12回表終了時に同点なら裏を行わず、12回裏に同点へ追いつけばその時点で終了。通常シーズンとポストシーズンの成績は別。試合方式はこの個別ページの旧記載より、上記の2026年8月24日の両リーグ改定を優先する。
- セの同率順位は勝利数、当該球団間の対戦勝率、リーグ内勝率、前年順位。パは勝利数を挟まず、当該球団間の対戦勝率、リーグ内勝率、前年順位。[パの公式アグリーメント抜粋](https://npb.jp/games/2019/info_cspl.html)が確認できる一次資料。パの2026年の個別開催概要は確認できていないため、同率規定の最新版を今後再確認する。
- [日本シリーズ2025公式要項](https://npb.jp/nippons/2025/information.html)：先に4勝、第7戦まで延長12回、第8戦以降は延長無制限。第8戦は第7戦と同じ球場、第9戦は移動日を挟んで別球団本拠地。[2026年の公式日程](https://npb.jp/nippons/2026/)は第1・2・6・7戦がセ、第3〜5戦がパ。奇数年は逆とする。2026年の詳細要項は現時点で確認できておらず、延長と追加試合は2025要項を暫定根拠とする。公表後に再確認する。
- DHは開催地側リーグの制度を適用。[2027年からのセDH採用決定](https://npb.jp/news/detail/20250804_05.html)を踏まえ、ゲーム内2027年以降のポストシーズンは双方DHとする。未来の日本シリーズ固有の特例は未確定で、現時点の公表制度を引き継ぐゲーム上の方針。通常シーズン全体のDH年度切替は別課題。

## 実装と保存

`playoff.js`にシリーズ作成・終了・遷移・次試合の開催条件を集約し、`playoffGame.js`経由で両操作を進める。引分は消化試合数に加算するが勝数は加算しない。完了／途中のシリーズを再作成しない。日本シリーズ第8戦以降に同点の結果が渡された場合は、不正な終了として拒否する。

`quickSimGame`に延長上限・ポストシーズンの打席途中終了・引分決着条件を渡す。延長無制限はJSONに残る`null`で表現。既存の通常シーズンの12回上限、打球物理、投手の先発追跡・回またぎ交代条件は維持。空打順や過剰な計算は例外で中断し、架空の勝敗を記録しない。

まとめてシムは各試合後に画面へ反映し、試合間で操作を返す。中止・失敗時は確定済みの試合まで保持する。1回の実行は最大40試合の安全弁を持つが、そこに達してもシリーズを打ち切らず次回へ続く。

既存`offseasonPlan`に`stage: postseason`として進行を保存。球団参照はID・表示情報・シーズン成績だけに縮約し、選手・キャリアログを重複保存しない。選手はライブの`teams`から検索して起用し、成績は`playoffStats`へ記録する。編成画面での保存もプレーオフへの復帰先を維持。日本一確定後の履歴・メール・信頼度更新は連打で重複させない。

順位表、CS出場判定、年度順位記録を`standings.js`へ統一。勝率は丸めず比較し、引分を分母に含めない。対戦成績は現在の全球団結果マップが球団の勝敗・引分と一致する場合に限り使用する。旧セーブ等で記録不足なら次の記録済み条件へ進み、不足を画面に明示する。前年順位もない完全同率は球団ID順をゲーム上の復帰用代替とし、NPB規定による確定とは扱わない。新しい年度順位記録に引分も保持する。
