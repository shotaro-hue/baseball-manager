# 財務画面：選手契約年俸（年額）

基準main: c39882596a8c7390f9ef2bb1d2f9066d7981c025（PR420〜425反映済み）。2026-10-09。

## 集計と表示

- 対象は現在の球団の `players`（一軍）と `farm`（二軍）。FA市場、スカウト候補、他球団選手は含めない。
- `育成` が真なら配列にかかわらず育成へ分類。それ以外は一軍支配下／二軍支配下。専用の育成配列はない。
- 同一IDは一度だけ集計。playersを先に読むため、重複時は一軍側の契約・所属を採用。IDのない異なる選手は別人として扱う。同じオブジェクトの重複は除外する。
- 合計は3区分の合算。既存 `fmtSal`、内部単位は万円を維持。集計は毎描画に現在の球団から算出し、永続stateを追加しない。
- 数値0は記録済み。null/undefinedは未記録。文字列（空文字含む）、負数、NaN、Infinityは不正。暗黙の数値変換を行わない。
- 未記録・不正値があるときは有効額のみを「確認できた分」と表示し、不完全である旨と人数を示す。完全な年俸総額と扱わない。
- 年俸上位6人は同じ所属母集団から有効額のみを降順で表示。所属区分を併記。同額は元の所属順。未知年俸は順位判定不能として除外し、その旨を表示する。
- 「年額」は契約額。予算控除の累計・支払済み額ではない。支払済み額を推測・新設しない。

## 副作用と描画経路

`HubShell` → `HubContentRouter` の finance → 遅延読込 `FinanceTab`。PCは監督メニュー、モバイルはメインメニューの「その他」→「球団運営」。表示コンポーネントは共通。

新しいentries/ランキング配列のみ並べ替え、元配列・選手オブジェクト・編成・予算を変更しない。保存処理、v4保存形式、IndexedDB構造を変更しない。昇降格・契約変更・獲得・放出後も現在データから再計算する。

年俸欄のみ局所CSSで明色背景と14px文字を設定。既存財務タブの旧ダーク背景でも内訳を読めるようにする。他カードの全面改修やレスポンシブ境界の変更は対象外。

## 未解決の別課題（今回の対象外）

- 年俸の支払時期、契約時・年度更新時の予算控除ルール。
- コーチ継続給与、出来高・タイトル賞与・オプトアウトの精算。
- 本拠地・ビジター別の収入ルールと年間収入予測。
- 契約評価式、ゲームバランス。
- 財務画面全体の配色・入力ラベル・その他の旧UI。

これらは表示修正によって解決した扱いにしない。旧SPECの「年俸シーズン中分割」の説明を、本変更の支払実装の証拠と解釈しない。
